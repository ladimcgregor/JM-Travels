This folder is intentionally empty at launch.

The brief is explicit: do not fabricate testimonials. Add a real one here as soon as
you have a customer's written permission to publish it, using this frontmatter shape:

---
customerName: "Ada"
destination: "Zanzibar"
tripType: "Couples"
date: 2026-10-01
quote: "The exact words the customer used, or a lightly trimmed version they've approved."
photo: "/images/testimonials/ada.jpg"   # optional
videoUrl: ""                             # optional
featured: true
---

Save it as a .md file in this folder (e.g. ada-zanzibar.md) and it will appear
automatically on the homepage and the Testimonials page. Until then, both pages
show an honest "building our track record" state instead of an empty gap.
